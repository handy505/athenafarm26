Method (POC): carbon = device runtime × rated power × grid emission factor 0.494 kgCO₂e/kWh. Unlike traditional IoT, every figure is derived from a Farm Event with start/end time and reason — audit-ready for ESG reporting and traceability disclosure.
Scenario 定義 / Definition（YAML）
Scenario 描述「今天農場發生什麼」— 不模擬 Sensor，而是模擬農場行為。新增 Scenario → Replay → Event Engine 分析 → 確認 Event，可整合 CI 做 Event Regression Test。
A scenario describes "what happens on the farm today" — we simulate farm behavior, not sensors. Add scenario → replay → event-engine analysis → verify events; CI-ready for event regression tests.
